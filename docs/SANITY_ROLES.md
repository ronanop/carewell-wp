# Sanity roles (P1.6)

Configure in [Sanity Manage → Members](https://www.sanity.io/manage/project/ndeeiwkw/members):

| Brief role | Sanity approach |
|------------|-----------------|
| **Admin** | Project Administrator — full access |
| **Editor** | Editor — content create/update/publish |
| **SEO Manager** | Custom role (Growth plan) limited to SEO fields, **or** Editor with Studio training to use SEO groups only |

Until a custom role is configured, use:

1. **Administrator** — developers / clinic lead  
2. **Editor** — content team (pages, services, blog, gallery)  
3. **Viewer** — read-only stakeholders  

API tokens:

- **Editor** — content import / patches  
- **Developer** — schema deploy + Studio tooling  

Revoke unused tokens after migrations.
